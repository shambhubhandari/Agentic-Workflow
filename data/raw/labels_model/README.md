# Model-generated labels

Label sets generated by frontier language models during development, used to compare
extraction quality across hardware configurations. **No metric reported in the manuscript
derives from these files.** The reference standard for all reported precision, recall, F1
and MCC values is `data/raw/labels_expert/` — 25 papers, 201 judgements, produced by a
domain expert. These are included for completeness of the development record.

| directory | source | coverage |
|---|---|---|
| `gemini/` | Gemini Pro | 50 papers, 450 judgements |
| `claude/` | Claude Opus | 15 papers, 135 judgements |

Both use the same schema and the same `y` / `n` / `na` vocabulary as the expert labels,
so they can be scored the same way — but scoring an extractor against a model-generated
reference measures agreement between two models, not accuracy. A parameter both miss is
recorded as a true negative and inflates recall.
