# Figures

Generated by `make figures`, which runs `src/acv/visualization/`. Generators are code and
live in the package; only their outputs land here.

Figures are named by content to preserve referencing under manuscript reordering.

| file | appears as | shows |
|---|---|---|
| `pass_agreement.pdf` | Figure 2 | repeatability across two identical extraction passes |
| `extraction_accuracy.pdf` | Figure 3 | per-field recall and precision against the expert labels |
| `parameter_reporting_gaps.pdf` | Figure 4 | how often each required parameter is not located |
| `lattice_parity.pdf` | Figure 5 | recomputed against published lattice constants |

Every figure here regenerates from shipped data and supports a value in the registry.

The manuscript's other two figures are **deliberately absent**. The pipeline schematic is
a hand-drawn diagram, and the relaxed-geometry renderings are built from SIESTA output
files this release does not distribute. Un-generator-backed figures are explicitly excluded to prevent decoupling between plot artefacts and their source logic.
